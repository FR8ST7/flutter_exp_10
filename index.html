Android Build Target Overview

Complete steps to configure, verify, and build a Flutter application for Android devices.

Step 1-3
Verify Environment
Run flutter doctor & accept licenses with flutter doctor --android-licenses.
Step 4
Create App
Create android_app directory using flutter create android_app.
Step 5
Run on Device
Test application on emulator/device using flutter run.
Step 6-8
Build & Locate APK
Compile APK under build/app/outputs/flutter-apk/app-release.apk.
# 1. Check Flutter & Android licenses
$ flutter doctor
$ flutter devices
$ flutter doctor --android-licenses

# 2. Create project and build APK
$ flutter create android_app
$ cd android_app
$ flutter build apk

# 3. Locate compiled APK
$ ls build/app/outputs/flutter-apk/app-release.apk
