Experiment Steps Flutter Lab Exp 10
  • Step 1: Check Flutter flutter doctor
  • Step 2: Check Devices flutter devices
  • Step 3: Toolchain Licenses flutter doctor --android-licenses
  • Step 4: Create Application flutter create android_app & cd android_app
  • Step 5-8: Run, Build & Test APK flutter run & flutter build apk

# Install APK onto Connected Android Emulator or Device
$ adb install build/app/outputs/flutter-apk/app-release.apk

# Launch App directly
$ flutter run -d android
